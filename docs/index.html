Session JSON

粘贴 ChatGPT Web session，或拖入一个或多个 JSON 文件。

Session 数据从这里获取

先在浏览器登录 ChatGPT，然后打开 https://chatgpt.com/api/auth/session ，复制页面显示的整段 JSON，粘贴到下方输入框。

这段 JSON 包含 accessToken 和 sessionToken，等同敏感登录凭证，不要发给别人。

等待输入。

转换结果

当前输出为 sub2api 导入 JSON。

ChatGPT Web session 一般没有 `refresh_token`；缺少真实 `id_token` 时 CPA、Cockpit、Codex 和 AxonHub 会构造 Codex 可解析的占位 JWT claims。Codex 和 Codex-Manager 会保留空 `refresh_token`；AxonHub 缺少真实 `refresh_token` 时会写入占位值。

sub2api 导入与服务器数据

仅在选择 sub2api 输出格式时可用；这里用于填写 sub2api 地址、Bearer Token、分组与代理，并查看服务器持久化账号。

填写或确认连接信息后，可以保存配置；需要分组/代理列表时点击“同步分组/代理”。
01

连接与认证

这里只填域名、IP:端口或 base URL；API 路径由 TokenManager 自动补齐。

服务器代理模式下，浏览器不会直接访问这个地址。
保存后不会明文回显；需要更换时重新填写即可。
02

导入行为

先设置导入账号默认参数，再选择是否需要绑定分组。

数值越小通常越优先。
写入 concurrency；0 表示不额外并发。
写入 rate_multiplier。
留空时按 access token 的 exp 自动写入。
写入 WebSocket v2 mode。
服务器代理模式已启用时，保存的配置会持久化在服务器；导入请求由 TokenManager 发起。
03

绑定分组与代理

分组列表占整行显示，搜索后勾选即可；不用按 Ctrl/Cmd 多选。

未选择分组
先点击“同步”，TokenManager 会从 sub2api 读取可用分组。
不选择分组时，导入账号不额外绑定分组。
未选择代理
先点击“同步”，TokenManager 会从 sub2api 读取可用代理。
选择多个代理后，导入时会为每个账号随机分配一个代理；留空使用 sub2api 默认策略。

服务器已保存账号

搜索、勾选、批量更新 sub2api 账号。

填写 Bearer Token 后可刷新服务器账号列表。
